# Session Log: 2026-03-17

## Objectives
- Make `All` the default park overlay filter.
- Replace the old one-shot `All` reveal with a gradual zoom-banded POI reveal.
- Reduce mid-zoom crowding by delaying the full local POI set until zoom 9.

## Knowns (Resolved)
- **Default Filter**: `dashboard-rebuild/src/App.tsx` now initializes `parkLayer` to `all`, so the app opens in `All` mode by default.
- **All-Mode Architecture**: `dashboard-rebuild/src/components/Map.tsx` no longer uses a single `parks_all` layer. `All` mode is implemented as a dedicated layer stack: `all_national`, `all_state`, `all_local_top`, `all_local_major`, `all_local_regional`, `all_local_dense`, `all_local_full`.
- **Local POI Definition**: “Local” is not a separate source field. It is derived in MapLibre filters as `national === 0 && state === 0`.
- **Reveal Metric**: Local reveal ordering is based on `visitor_counts_postcovid`, not pre-COVID volume or geographic spreading.
- **Current Reveal Curve**:
  - `< 4`: national only
  - `4` to `< 5`: national + state
  - `5` to `< 6`: local threshold `>= 4000`
  - `6` to `< 7`: local threshold `>= 1000`
  - `7` to `< 8`: local threshold `>= 450`
  - `8` to `< 9`: local threshold `>= 250`
  - `>= 9`: all local POIs
- **Visual Consistency**: All `all_*` layers use the same percent-change color ramp, `circle-opacity: 0.96`, dark stroke `#020617`, and the smaller “All mode” radius ramp. The isolated `National` and `State` modes keep their larger focused radius ramp.
- **Initial-Load Sync**: `Map.tsx` now uses a `syncParkLayerVisibility()` helper plus a `PARK_LAYER_VISIBILITY_MAP` to apply the correct park overlay both on initial map `load` and on later button toggles. This fixed a first-render risk where the default filter could be missed before style load completed.
- **Interaction Priority**: Park click precedence still runs through a single `queryRenderedFeatures()` path, and the clickable park-layer list now includes every `all_*` layer as well as `parks_national` and `parks_state`.
- **Verification**:
  - `npm run build` passed after the default-`All` implementation and again after stretching full density to zoom 9.
  - Browser QA on local preview (`vite preview`) confirmed:
    - `All` is active on first load.
    - Zoom 3 shows national-only.
    - Zoom 4 shows national + state.
    - Zoom 5, ~6.4, ~7.3, and ~8.9 show progressively denser local bands.
    - Full local density is not active until past zoom 9 (verified at ~9.6).
    - `All`, `National`, and `State` buttons toggle cleanly.
    - Browser console stayed clean; only the longstanding Vite chunk-size warning appears during build.
